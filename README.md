# Cluckroll privacy policy

The privacy policy for the Cluckroll Android app (com.eurekadigilabs.cluckroll), served by GitHub Pages at
https://cherman95.github.io/cluckroll-privacy/ . `ads-config.json` is the remote ads kill switch the app fetches
(values can only tighten the built-in limits).

Edited from `docs/privacy-site/` in the game repo.
